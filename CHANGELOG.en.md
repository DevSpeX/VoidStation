# Changes

English version of `CHANGELOG.md`, shown in the update dialog when the interface is set to English.
Same format and the same headings as the German file, followed by bullet points.

Calendar versions (since 2026.11): `## 2026.11 – 2026-11-07` (the November release train),
hotfixes to it `## 2026.11.1 – …`. New changes go first under `## Testing – <date of the last change>`
at the top; `vspub --release` or `vspub --hotfix` assigns the number when releasing (see `RELEASING.md`).
Older versions (up to 0.15.0) still use the old numbering.

## Testing – 2026-11-15
- **Six new languages: Dansk, Svenska, Norsk bokmål, Íslenska, Suomi and Eesti** – Settings → Language. Machine-translated like the other languages (corrections welcome as a pull request), with date, time and numbers in the language's format and country names in the TV filter; radio and TV suggest Denmark, Sweden, Norway, Iceland, Finland or Estonia (Swedish with a Finnish time zone: Finland). The on-screen keyboard gets the layouts Dansk, Svenska, Norsk, Suomi (same as Swedish), Íslenska (ð þ æ ö, acute vowels on the accent page) and Eesti (ü õ ö ä, š ž). The installer and the stick's boot menu know the six languages from the next live ISO on; keyboard and time zone are preset (Copenhagen, Stockholm, Oslo, Reykjavík, Helsinki, Tallinn). Iceland now shows up by name in radio and TV in every language (instead of “IS”)
- **Own package repository**: Whatever Void lacks now comes as a signed package from VoidStation's own package repository (`repo.voidstation.de`, built from the official sources, build recipes public on GitHub as `Panther92/voidstation-packages`). This covers the XLibre display server (formerly from xlibre-void – the same packages, nothing gets reinstalled), chdman (package `vs-chdman`, which makes the update 3 MB smaller) and 14 AppCenter programs: Heroic, itch, Moonlight, PCSX2, RMG, Azahar, Flycast, Cemu, xemu, FreeTube, Brave, LibreWolf, Mission Center and LocalSend. The emulators and Moonlight are built against the system's Qt and SDL, so they follow the look of the system and are smaller; Moonlight is now available for 32-bit too. If you already have one of these programs, the next update switches it to the package (it is listed there) – settings and save games stay where they are, the unpacked version is only removed once the package is installed. Future updates come with the package updates. Discord, Spotify, DuckStation and Brave Origin are still downloaded straight from their makers
- **Mullvad VPN from the package repository**: Instead of rebuilding Mullvad's .deb on every device, VoidStation installs the ready-made package `mullvad-vpn` (Mullvad's signature is checked at build time). Existing installations switch with the next update, account and settings are kept. New Mullvad versions come with the package updates, after which the service restarts with the block held
- Mullvad VPN: Switching to the package from the own package repository aborted ("Directory not empty") and left Mullvad without its service. The switch now clears the folder runit had created for the service first; an aborted switch is repaired with the next update
- **Error report at the press of a button**: Settings → System → Error report → "Create report" – or `vsctl report` in a terminal, which also works over SSH when the interface is stuck – writes a text file to the network share under `vs-reports`: VoidStation version, device (CPU, graphics, display, audio, drives, USB, controllers), key package versions, running services, the settings and the logs (launcher, updates, home screen, programs, X server, kernel messages, installer). Removed beforehand: passwords and keys, Wi-Fi names, the second half of MAC addresses, public IP addresses and e-mail addresses; serial numbers never go in. Nothing is sent anywhere – "View contents" shows what is in it, and the file can be attached to an issue on GitHub from your PC. The ten newest reports are kept, VoidStation clears out older ones. `vsctl report --print` only prints the report
- **Sega and PC Engine: Mednafen in the AppCenter**: The new emulator Mednafen plays Master System, Mega Drive, Game Gear, Saturn and PC Engine (CD games too). It has no menu of its own – everything goes through VoidStation: one tile with a shared game list from the new folders `share/ROMs/megadrive`, `mastersystem`, `gamegear`, `saturn` and `pcengine` (created by the update), button mapping with one Sega pad for all five systems (A/B/C in a row on □/✕/○ or X/A/B, above them X/Y/Z on L1, △/Y, R1; Master System and Game Gear use B and C as buttons 1 and 2, PC Engine as II and I), the left stick steers as well, save states and fast-forward can be put on controller buttons. Options: aspect ratio (pixel-perfect, original, stretch), smoothing, shaders (sharp, Scale2x, SABR, CRT), filters (HQ2x–4x, Scale2x–4x, 2xSaI …) and scanlines – each for all five systems at once. Saturn needs a BIOS from your own console in `share/ROMs/saturn/bios` (the name doesn't matter, VoidStation recognises Japanese and European/American versions by their contents and sets them up) and a fast 64-bit computer; PC Engine needs the System Card in `share/ROMs/pcengine/bios` for CD games only. CD games as `.cue`, `.ccd`, `.toc` or `.m3u` – Mednafen does not read `.chd` or `.iso`, and cannot do Mega-CD or 32X. Mega Drive used to run through RetroArch only
- **Wii games and multi-disc games in the game list**: Dolphin now also shows the new folder `share/ROMs/wii` and the usual Wii formats `.wbfs`, `.wia`, `.ciso`, `.gcz` and WiiWare as `.wad` (so far only `.iso`, `.rvz`, `.gcm` from `gamecube`). PlayStation, GameCube/Wii, Saturn and PC Engine read `.m3u` playlists: the playlist is listed as one game and its discs no longer show up separately; per-game options and game profiles on PlayStation follow the first disc
- **Options for all remaining emulators**: Nintendo 64 (RMG), Dreamcast (Flycast), Xbox (xemu), Nintendo DS (melonDS), Super Nintendo (Snes9x), NES (Nestopia), arcade (MAME), ScummVM, C64 (VICE) and Atari 2600 (Stella) now have the “Options” card with “VoidStation settings | Customize”, General, Picture and Picture style as well – only RetroArch keeps its own menu. RMG: resolution, aspect ratio, anti-aliasing (MSAA), FXAA. Flycast: resolution, widescreen patch, integer scaling, smoothing, sharpen distant textures, texture upscaling (xBRZ), graphics API. xemu: resolution, aspect ratio, smoothing, graphics API. melonDS: resolution, screen layout, swap screens, integer scaling, smoothing. Snes9x: aspect ratio, smoothing, 13 of the emulator’s filters (scanlines, NTSC, HQ2x–4x, xBRZ …), mute game. Nestopia: aspect ratio, filter (sharp, pixel-perfect, soft, CRT, MMPX, OmniScale), NTSC filter, mute game. MAME: aspect ratio, integer scaling, smoothing and four shaders (CRT-Geom, CRT-Geom Deluxe, HLSL, LCD). ScummVM: aspect ratio, smoothing, nine filters (HQ, AdvMAME, 2xSaI …), mute game. VICE: aspect ratio, border, upscaling, filter (CRT, off, Scale2x), mute game. Stella: aspect ratio, smoothing, TV filter (RGB, S-Video, Composite …), scanlines. <kbd>Y</kbd> on a game sets resolution and aspect ratio or widescreen for that game only on RMG and Flycast. Defaults, applied once: Flycast and melonDS start at 2× resolution (3× and 4× with a dedicated graphics card) – melonDS switches to its OpenGL renderer for that, “Original” brings back the more accurate software renderer. Everything else stays as the emulators ship it
- **Options now for PSP, GameCube/Wii, Wii U and 3DS, too**: PPSSPP, Dolphin, Cemu and Azahar get the same “Options” card in the game list as PlayStation, Game Boy and DOS – first “VoidStation settings | Customize”, below that General, Picture and Picture style. PPSSPP: resolution, aspect ratio, integer scaling, sharpen distant textures, anti-aliasing (MSAA), 25 of the emulator’s shaders (including “Original colors” for the PSP’s screen, FXAA, FSR), graphics API, mute game. Dolphin: resolution, aspect ratio, widescreen patch, sharpen distant textures, MSAA, 38 shaders, compile shaders in the background (against short stutters), graphics API, mute game. Cemu: aspect ratio, upscaling filter, compile shaders in the background, graphics API – on Wii U the resolution is still set per game by the graphic packs in Cemu. Azahar: resolution, screen layout (stacked, large screen, side by side …), swap screens, integer scaling, smoothing, texture upscaling, compile shaders in the background, graphics API. <kbd>Y</kbd> on a game sets resolution, aspect ratio or layout for that game only on PPSSPP, Dolphin and Azahar. Defaults, applied once: Dolphin and Azahar start at 2× resolution (3× and 4× with a dedicated graphics card), PPSSPP at 4× with a dedicated graphics card. “Picture in games” still applies to these four
- **Picture style for the emulators**: The game list options now have a “Picture style” column under “Customize”. “Shader” offers what the emulators ship themselves – CRT and scanline looks (CRT-Lottes, CRT-Hyllian, NTSC …), pixel-art smoothers such as xBR or MMPX, sharpening, film grain and more: PlayStation (DuckStation) 17 styles, PlayStation 2 (PCSX2) its TV filters, DOSBox 15 instead of three. For Game Boy and GBA, VoidStation bundles mGBA’s latest shaders itself (Void’s mGBA-Qt package ships none), including color profiles of real devices (GBA SP 101, DS Lite, Switch Online …) and LCD grids. New: **Original colors** – GBA and GBC games were made for the pale screens of their day and look garish on a TV; VoidStation picks the matching color profile per game, Game Boy games stay as they are. The shader is off by default. Tools such as calibration or mirroring stay in the emulator
- **Own style “VoidStation Clear”**: for PlayStation, a shader of our own that sharpens edges and textures without adding noise to flat areas and without bright halos (PlayStation 2 is already sharpened this way by default). For Game Boy and GBA it keeps pixels sharp and evenly sized at non-integer scales – with “Integer scaling: Off” the game fills the screen without blur. On DOSBox this is the “Sharp” style, which already is the default
- **Color** (PlayStation and PlayStation 2): Natural, Vivid (more saturation, slightly more contrast) or Bright (for dark games). Same formula and same values on both consoles, so the same impression
- **Picture style per game**: <kbd>Y</kbd> on a game (mouse: gear) now also sets shader and “Smooth edges” for that game only – for PlayStation and PlayStation 2 in the emulator’s own game settings, for Game Boy/GBA and DOS VoidStation remembers it. Per-game options are therefore now available for Game Boy and GBA, too
- **Preview images**: With the focus on a style, the card shows a sample image for it – a test scene drawn for this purpose, rendered through the emulator’s real shader. Ten DuckStation styles (the ReShade shaders) have no image yet
- **Smooth edges (FXAA)** for PlayStation and PlayStation 2, on by default whenever the computer has graphics acceleration: jagged diagonal edges are smoothed at almost no cost. DuckStation smooths at render resolution, before the picture is scaled up to the TV. On PlayStation the switch is set to “Automatic”: for known pixel-art games (Castlevania, Final Fantasy Tactics, Legend of Kartia …) smoothing stays off because it would soften text and sprites; “On” always smooths. Like all defaults, only once – whatever you change under Options → Customize → Picture style stays
- **Picture in games** (Settings → Display, 64-bit only): “Sharpen” or “Sharpen + smooth edges” for all games and emulators from the AppCenter that draw through Vulkan – such as Steam with Proton, Dolphin, Cemu, PPSSPP or xemu. This uses vkBasalt, which VoidStation installs when you switch it on. Off by default. PlayStation and PlayStation 2 are excluded (they have the picture style in their options), OpenGL programs are not affected, nor are 32-bit games
- DOS: The soundfont for General MIDI was not installed on existing devices – the download was aborted after five seconds
- **Tuned under the hood** – with Void's standard kernel; no custom kernel is built. Machines with less than 8 GB of RAM now swap to compressed memory first (zram) instead of to the SSD, on their own; until now this was opt-in, and the swap file stays as a reserve. Sound (PipeWire) may take real-time priority and crackles less often when the machine is busy. If memory runs out anyway, a memory guard (package `earlyoom`) ends the largest program – a browser tab first – before the machine hangs for minutes; the interface, picture and sound stay. The kernel runs fully preemptible (`preempt=full`, switched at runtime – the EFISTUB and GRUB command lines stay as they are). While a game, an emulator or Steam is running, the CPU governor is set to “performance” so the clock does not have to ramp up on load changes; once the game is closed or the emulator is paused in the background, the previous setting applies again. SSDs are trimmed once a week (TRIM), never during a game. Sound, zram and the memory guard take effect after the restart. Each part can be switched off on its own in the terminal and then stays off across updates: `sudo voidstation-tune off oom`, `… off preempt`, `… off trim`, `… off perf` and `sudo voidstation-zram off`; `voidstation-tune status` shows the state. How much this helps depends on the machine – most with little RAM and few cores
- **CHD images are now recognised**: VoidStation reads the serial and checksum from `.chd` files too (PlayStation and PlayStation 2, 64-bit only) – using the bundled chdman, which only pulls a few megabytes out of the image for this. Per-game options, game profiles, patches and the 50 Hz switch therefore also apply to CHD games that were not converted by VoidStation itself
- **Frame rate and widescreen patches per game, automatically**: PCSX2 and DuckStation ship a collection of official patches. Before every start VoidStation checks whether there is a patch for exactly this game (serial) and enables it in the emulator’s per-game settings. PlayStation 2: frame rate patch (50 or 60 frames per second instead of 25/30) – out of the box only on computers with at least four cores at 3 GHz or more, because many of these patches need an overclocked PS2 CPU; VoidStation also sets the overclock named in the patch (130 % or 180 %), patches needing 300 % only on explicit request. PlayStation: frame rate patch and the real widescreen patch (16:9 without stretched displays) where they exist. Where a game has a patch, its options (<kbd>Y</kbd> on the game) show a “Frame rate patch” or “Widescreen patch” row to switch it on and off. If you turn a patch off inside the emulator, it stays off
- **DOS: music via General MIDI**: DOSBox now comes with a soundfont (package `soundfont-fluid`, about 140 MB). Games set to “General MIDI” in their own SETUP now have wavetable-quality music – so far they usually stayed silent. Existing devices fetch the package in the background the next time DOSBox starts; it applies from the start after that. If you chose a MIDI device yourself in your `dosbox-staging.conf` (e.g. MT-32), it stays
- **More in the emulators’ VoidStation settings** – as always applied once and only where you have not set anything yourself. PlayStation 2 (PCSX2): the widescreen patch and the no-interlacing patch are on out of the box and take effect in every game PCSX2 ships an official patch for (widescreen can still be switched off per game, <kbd>Y</kbd> on the game); the picture is sharpened and scaled to the screen size, which costs little even without a dedicated graphics card. PlayStation (DuckStation): games read data from the CD four times as fast, and video sequences lose their colour blocks. These presets have no row of their own on the “Options” card; “VoidStation settings” applies them, and they can be changed inside the emulator
- **PAL PlayStation games without judder**: European versions run at 50 frames per second. If the screen offers 50 Hz at its resolution, VoidStation switches to it for the duration of the game and back afterwards – the picture goes black briefly when starting and quitting. Applies to DuckStation; PlayStation 2 stays at 60 Hz because many PAL games there offer 60 Hz themselves
- **Folder for HD textures**: Texture packs for PlayStation 2 and PlayStation games go into `ROMs/ps2/textures/<serial>/replacements` or `ROMs/psx/textures/<serial>/replacements` in the share; the emulators then pick them up by themselves. Each folder contains a `LIESMICH.txt`. VoidStation does not download packs itself
- **Simpler emulator options**: The “Options” card in the game list now starts with just one switch – “VoidStation settings” or “Customize” – and “Mute game”. With “VoidStation settings” the presets for your device apply, including the game profiles; only “Customize” reveals the individual switches (General on the left, Picture on the right). If you have already changed something, even inside the emulator itself, the card opens on “Customize” with your values. Switching back to the VoidStation settings remembers your values, “Customize” brings them back. The options for a single game (<kbd>Y</kbd> on the game) stay as they are
- **Game profiles – VoidStation sets up known games by itself**: For about 190 PlayStation and 90 DOS games, VoidStation now knows what suits them and applies it when a game is started from the game list. PlayStation (DuckStation): new option “Smooth textures” (Automatic / On / Off). On Automatic, 3D games such as Tekken 3, Gran Turismo or Crash Bandicoot get smoothed textures instead of coarse pixel blocks; games with pixel art, pixel characters or pixel fonts (Castlevania, Final Fantasy Tactics, Legend of Kartia …) stay sharp. Text and menus are never smoothed. Games outside the list: only racing games, first-person shooters and flight simulations are treated as 3D, everything else stays as it is. DOS: with “CPU speed” on Standard, known games run at a fitting speed – early PC games such as Alley Cat or Digger slowed down (new level “XT”), Commander Keen 4–6 like on a 386, Wing Commander II, X-Wing or Wolfenstein 3D like on a 486, Duke Nukem 3D, Quake or The Settlers II at full power. Whatever you choose for a game yourself (<kbd>Y</kbd> on the game) always wins; setting the general option to anything other than Automatic or Standard turns the profiles off for that option. The lists are tables in `gamedb/` (format: `LIESMICH.txt` there)
- New emulator presets – applied once and only where you have not set anything: DOSBox shows sharp pixels instead of the imitated CRT (Options → Screen → “CRT” brings it back). PCSX2 has the new option “Sharpen distant textures” (anisotropic filtering: floors and walls stay sharp into the distance), set to 16× out of the box with a dedicated graphics card
- Per-game options: for games in subfolders the choice did not end up in the game settings of DuckStation/PCSX2 and seemed to jump back to “Same as everywhere” after the first start
- **Convert bin/cue to CHD** (PlayStation and PlayStation 2, 64-bit only): When the game list finds games made of `.cue` and `.bin`, a card asks once whether to convert them to CHD – one file per game, smaller, lossless. Then it asks “Delete the old files?”: with “Keep” the originals move to `ROMs/<system>/_umgewandelt`, with “Delete” they are removed. Either way only after the game's CHD file is finished and verified; if a game fails, it stays as it was. The conversion runs in the background with progress, can be cancelled and checks free space first. If you say “No”, you are only asked again for new games and find a “Convert to CHD” button in the bar. Covers, per-game options and the detected serial number move along. Games without any `.cue` are found too: a single `.bin` or several tracks like `Tekken 3 (Europe) (Track 1).bin`, `(Track 2).bin` … – VoidStation creates the missing cue sheet itself (data track MODE1/MODE2, audio tracks with their pregap) and puts all tracks into one CHD file, music included. Even before converting, such tracks show up as one game in the list (“Tekken 3” instead of three times). The tool (`chdman` from MAME 0.289) is built by VoidStation from source and shipped with it (`tools/build-chdman.sh`) instead of installing all of MAME. Texts in all languages
- **Game list: subfolders and bin/cue**: Games may now live in their own subfolders (up to three levels below `ROMs/<system>`, e.g. `ROMs/psx/Tekken 3/…`); the tile finds and starts them. Images made of `.cue` and `.bin` now show as a single entry per game – the `.bin` files a `.cue` sheet points to no longer appear on their own, and the size adds up all files. Multi-disc games keep the disc number in their name ("Final Fantasy VII (Disc 2)"). A `cover.jpg`, or a picture named like the game, in the game's folder is used as its cover. The `bios`, `Cover` and `textures` folders and hidden folders do not count; MAME still only looks directly in `ROMs/mame`, and for DOS and ScummVM every subfolder remains one game
- **Screenshots**: <kbd>F12</kbd> on the keyboard, <kbd>Start</kbd> + <kbd>Select</kbd> together on the controller or the `vsshot` command in a terminal (also over SSH) save the whole screen as a PNG in the new `Screenshots` folder of the share. The name starts with the program and the game from the game list, e.g. `DuckStation_Crash Bandicoot_2026-11-12_19-35-02.png`; for Steam and the browsers the window title takes the game's place, on the home screen it is simply `VoidStation_…`. A short notice at the bottom right confirms it. The picture is taken the moment you press – still, a game that opens its pause menu on Start may already show it; use F12 then. Azahar (3DS): fast forward now uses Ctrl+T instead of F12 internally, the controller mapping stays the same
- Internal: the launcher, home screen, player, installer and Mullvad helper are now fully checked for type errors (mypy). Nothing changes in how they behave.
- TV: The filter column (countries and topics) now scrolls when it does not fit on the screen – before, the topics could not be reached at large scaling. A thin bar on the left of scrolling lists shows that there is more and where you are, also in the AppCenter next to the categories and the app list. Scrolling columns now fade out cleanly at the top and bottom
- **YouTube Light: chapters**: If a video has chapters, the timeline shows them as sections and the overlay shows the current chapter's name. <kbd>LB</kbd>/<kbd>RB</kbd> then jump to the previous or next chapter (like YouTube, first to the start of the current one), without chapters still by one minute. The chapter list opens with <kbd>Start</kbd> → top entry, or with the mouse via the list button at the top right
- Less load when idle: the home screen and the player no longer poll the controller 60 times a second, the controller mouse no longer 100 times – both only wake up when something actually happens on the controller. This mainly helps older computers; controls and key repeat stay the same
- Xbox controllers connected via Bluetooth show A/B/X/Y in the button hints instead of the PlayStation symbols (they report as "Xbox Wireless Controller" and were detected like a DualShock 4)
- **Classic web interface removed**: The start screen is now only the Qt program, which has been the default for a while. Gone are the web interface with its WebKit window, the Settings → System → Interface switch and the automatic switch to the web interface when Qt fails to start. If the start screen exits several times right after starting, VoidStation now waits longer before each new attempt (at most a minute) and notes this in `logs/frontend.log`. The update cleans up the old files, the start screen's Firefox profile and the WebKit data, and removes WebKitGTK unless another program needs it – that saves space on the SSD and makes the live ISO smaller
- **New in the AppCenter: Mullvad VPN** (Tools, 64-bit only). VoidStation downloads Mullvad's official Linux release from GitHub, checks its signature against Mullvad's code-signing key and turns it into a package of its own with the service and the command line (runit instead of systemd, without the Electron interface). Everything is controlled from the home screen: log in with the 16-digit account number (number pad, QR code to mullvad.net for the account), main page with world map and status card, choose a location by country and city, options for connect at startup, lockdown mode, allow home network (on by default so SSH and LocalSend stay reachable) and Mullvad's DNS filters, plus the account with its expiry date and log out. Top right, next to name and clock, a shield shows the state (connected, connecting, disconnected, internet blocked); A opens the page, X turns the VPN on and off – the tile does the same. New Mullvad versions arrive through Settings → Updates. Texts in all languages
- **Steam with an NVIDIA graphics card**: With the NVIDIA driver, Steam was missing the 32-bit driver libraries and either did not start or ran without graphics acceleration. VoidStation now installs them together with Steam (`nvidia-libs-32bit`, also for the older nvidia580 and nvidia470 drivers) and adds them to existing Steam installations with this update. It always installs exactly the driver's version; if the driver is not up to date right now, the package follows with the next system update. Nothing changes without the NVIDIA driver
- **Input method for Korean, Chinese and Japanese**: When the interface is set to 한국어, 简体中文, 繁體中文 or 日本語, VoidStation sets up fcitx5 with the matching input (Hangul, Pinyin, Zhuyin/Chewing, Mozc; Anthy on 32-bit) – once, in the background, as soon as there is internet. With a real keyboard, <kbd>Ctrl</kbd>+<kbd>Space</kbd> (or the Hangul/Zenkaku key) switches between Latin and the native script; the candidate list follows the light or dark theme. Works right away in programs started from the tiles, in the start screen's text fields after the next restart. The **on-screen keyboard** now has a Korean layout (2-Beolsik): characters combine into syllables as you type (ㅎ ㅏ ㄴ → 한), <kbd>⇧</kbd> gives ㄲ ㄸ ㅃ ㅆ ㅉ ㅒ ㅖ, backspace removes only the last part of the syllable, "ABC" switches to Latin. Chinese and Japanese still type Latin on the on-screen keyboard (picking candidates with the controller comes later)
- **Five new languages: Română, Türkçe, 한국어 (Korean), 简体中文 (Chinese, Simplified) and 繁體中文 (Chinese, Traditional)** – Settings → Language. Machine-translated like the other languages (corrections welcome as a pull request), with date, time and numbers in the language's format and country names in the TV filter; radio and TV suggest Romania, Türkiye, South Korea, China or Taiwan. Korean and Chinese use the matching variant of Noto Sans CJK (the same characters look different in Korea, China and Taiwan). - **On-screen keyboard over apps too**: In the browsers (Firefox including YouTube and the media libraries, LibreWolf, Chromium, Brave, Brave Origin) it opens by itself when you select a text field and closes again when you leave it. Same keys and layout as on the start page, plus Tab and cursor keys. Controls: A types, X deletes, Y space, LB/RB cursor, RT Shift, Start Enter, B closes; with a mouse just click the keys. It types like a real keyboard, including characters missing from the configured keyboard layout (€, @, accents, Cyrillic). If the field is in the lower half of the screen, the keyboard appears at the top. With a keyboard plugged in, the “Show keys” setting under Language → On-screen keyboard applies. Replaces the English Firefox extension FX OSK, which could only type inside web pages
