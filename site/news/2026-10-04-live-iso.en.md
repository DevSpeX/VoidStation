# The live ISO is here

VoidStation is now available as a live ISO to download – and that is now the only way to install VoidStation. One stick, one boot menu, one installer in the same tile design as the start screen.

Here's how: get the ISO from the [download page](seite:download), put it on a USB stick (Ventoy, Rufus or balenaEtcher), boot from it and pick your language in the boot menu. Take your time trying out the live system first – YouTube, TV, radio and VLC run straight from the stick. If you like it, the **Install VoidStation** tile puts the system on your SSD:

- on the whole SSD, next to Windows or Linux, into free space or partitioned manually with GParted
- without internet – everything comes from the stick, in about five minutes
- with an NVIDIA card from GTX 16xx / RTX 20xx on, via the “NVIDIA only” boot entry, right away with the NVIDIA driver

The ISO is hosted on SourceForge, with a SHA-256 checksum and a signature. How to check both is explained [on the download page](seite:download#checksum).
